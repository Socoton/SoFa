La Maison Perchée Project - AgendaButton

Un composant d'interaction calendaire intelligent

dates: 2 semaines || 1/12/2025 - 12/12/2025

AgendaButton est un projet d'interface utilisateur (UI) développé avec React et Next.js. L'objectif était de créer un bouton d'appel à l'action sophistiqué pour la prise de rendez-vous, intégré dans un environnement de design cohérent et moderne.
Ce projet met l'accent sur l'expérience utilisateur (UX) grâce à une thématisation poussée et une architecture logicielle robuste capable de gérer les contraintes du rendu côté serveur.

### Fonctionnalités Clés

  • Design System Personnalisé :Intégration complète de Chakra UI avec une charte graphique sur mesure (IBM Plex Sans pour la lisibilité technique et Alegreya pour l'élégance).
  • Architecture Next.js 16 :Utilisation des dernières fonctionnalités de Next.js pour une navigation fluide et optimisée.
  • Rendu Hybride (Client/Serveur) : Optimisation stratégique du chargement des composants pour garantir une hydratation parfaite et éviter les erreurs de rendu initial.
  • Interface Réactive & Accessible :Un design fluide s'adaptant à tous les types d'écrans tout en respectant les standards d'accessibilité.

### Stack Technique

  • Framework : React.js, Next.js 16 (App Router)
  • Langage : TypeScript (Typage strict pour une meilleure maintenabilité)
  • Librairie UI : Chakra UI

INRAE ECOSYS Project - IA Plant Model

FSPM for Crop Mixtures: C/N Dynamics & Multi-Organ Modeling

Timeline: 3 years || 01/09/2022 - 01/09/2025

Development of a plant model focusing on phenological and morphological traits. The model simulates environmental influence on resource acquisition and allocation (Light, C, N) among various shoot and root organs.

Key Features

  • Plant-Plant Interactions: Modeling competition and facilitation dynamics within intercropped systems (Crops/Legumes).
  • Carbon-Nitrogen Coupling: Simulation of C/N balances integrating symbiotic fixation and long-distance transport between sinks and sources.
  • Deep Learning Optimization: Enhancing simulation speed and calibrating complex parameters using neural networks (Surrogate Modeling).
  • Multi-Scale Architecture: Explicit 3D topology representation for realistic light interception and root soil exploration.

Technical Stack

  • Modeling Framework: OpenAlea (PlantGL, MTG, L-Py)
  • Language: Python (Scientific Stack: NumPy, SciPy, Pandas)
  • Deep Learning: PyTorch or TensorFlow (Optimization & Emulation)
  • Visualization: 3D integration via OpenAlea & Matplotlib

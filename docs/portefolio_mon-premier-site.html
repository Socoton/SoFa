La Maison Perchée Project - AgendaButton

Smart Calendar Interaction Component

Timeline: 2 weeks || 01/12/2025 - 12/12/2025

AgendaButton is a User Interface (UI) project developed with React and Next.js. The objective was to create a sophisticated call-to-action (CTA) button for appointment scheduling, integrated into a consistent and modern design environment.
This project focuses on User Experience (UX) through advanced theming and a robust software architecture designed to handle server-side rendering constraints.

Key Features

  • Custom Design System: Full Chakra UI integration with a bespoke visual identity (IBM Plex Sans for technical readability and Alegreya for elegance).
  • Next.js 16 Architecture: Utilizing the latest Next.js features for seamless and optimized navigation.
  • Hybrid Rendering (Client/Server): Strategic optimization of component loading to ensure perfect hydration and eliminate initial rendering errors.
  • Responsive & Accessible Interface: A fluid design that adapts to all screen sizes while adhering to strict accessibility standards.

Technical Stack

  • Framework: React.js, Next.js 16 (App Router)
  • Language: TypeScript (Strict typing for enhanced maintainability)
  • UI Library: Chakra UI

INRAE ECOSYS Project - IA Plant Model

FSPM for Crop Mixtures: C/N Dynamics & Multi-Organ Modeling

Source code (prototype = incomplete code)

Timeline: 3 years || 01/09/2022 - 01/09/2025

Development of a plant model focusing on phenological and morphological traits. The model simulates environmental influence on resource acquisition and allocation (Light, C, N) among various shoot and root organs.

Key Features

  • Plant-Plant Interactions: Modeling competition and facilitation dynamics within intercropped systems (Crops/Legumes).
  • Carbon-Nitrogen Coupling: Simulation of C/N balances integrating symbiotic fixation and long-distance transport between sinks and sources.
  • Deep Learning Optimization: Enhancing simulation speed and calibrating complex parameters using neural networks (Surrogate Modeling).
  • Multi-Scale Architecture: Explicit 3D topology representation for realistic light interception and root soil exploration.

Technical Stack

  • Modeling Framework: OpenAlea (PlantGL, MTG, L-Py)
  • Language: Python (Scientific Stack: NumPy, SciPy, Pandas)
  • Deep Learning: PyTorch or TensorFlow (Optimization & Emulation)
  • Visualization: 3D integration via OpenAlea & Matplotlib
